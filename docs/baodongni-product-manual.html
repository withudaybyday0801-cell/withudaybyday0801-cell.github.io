1. 产品概述

包懂你是一款以背包为主要品类的 AI 导购助手。消费者可以用日常语言描述用途、预算和偏好，通过对话获得选款建议，也可以围绕具体商品了解功能、查看详情并比较差异。

产品面向校园、通勤、休闲与短途出行等场景，关注容量、重量、背负结构、面料、风格与收纳需求，帮助消费者缩小选择范围、了解商品特点。

打开网页即可输入需求，或通过“选品推荐”开始选购咨询。商品卡片提供详情、分析和加入购物车入口；购物车中的商品可作为后续提问或比较的对象。“历史”支持查看已有会话，“新对话”用于开始新的选购咨询。

3. 需求理解与推荐方式

3.1 识别选购诉求

消费者无需熟悉专业参数，可以从“夏天背、轻一点”“上班用、不要太大”等描述开始。产品结合使用场景、携带物品与个人偏好，提炼轻便、透气、收纳或外观等主要诉求。

需求理解以个人表达为依据。通勤场景与电脑携带需求分别确认；颜色、容量和风格也由具体偏好决定。舒适、清爽等感受性描述用于了解选购方向，实际体验仍受负重、体型、天气和使用时长影响。

3.2 对应商品属性

选购需求与品类、容量、背负结构、面料、功能和场景等商品属性关联。其中，明确的预算、尺寸、容量范围及必备功能构成筛选条件；“最好、尽量”等偏好用于比较款式的适合程度。

需求表达对应的选购要素
“上班用，200 元以内”通勤场景、预算上限。
“至少 20L，最多 25L”容量范围。
“要装 14 寸电脑”电脑适配尺寸与电脑隔层。
“必须宽肩带、尼龙面料”肩带结构与面料要求。
“夏天舒服点，最好宽肩带”透气、背负舒适及肩带偏好。
“不带电脑了，其他不变”更新携带需求，延续其他选购要求。

电脑适配除标称英寸外，还需结合实际外壳与内仓尺寸判断。防泼水、日常防雨和有测试依据的防水能力分别呈现，便于了解适用范围。

3.3 逐步完善需求

对话从使用场景出发，逐步了解主要携带物品、必要容量、电脑尺寸、预算及背负、防水等偏好。快捷选项便于补充信息，也支持自由输入与随时调整。

涉及多款商品、指代不明确时，可通过选定商品继续咨询。对于无法同时满足的要求，例如容量既需至少 30L、又需不超过 10L，系统会提示冲突，协助确认优先需求。当前商品范围内没有合适选择时，可根据提示决定是否调整条件。

3.4 提供有依据的选购信息

商品说明、参数、图片和查询入口与相应商品关联。功能介绍以已有资料为依据；资料不完整的项目标明信息不足，便于进一步核实。

评价内容基于已有样本呈现，兼顾正面反馈与使用中需要留意的方面。复杂口语、主观风格或不完整信息仍可能影响理解与匹配结果，可通过补充描述、调整条件或明确选定商品继续交流。

4. 商品数据与适用范围

体验版包含 64 个独立的模拟商品条目，覆盖双肩包及少量托特包、斜挎包和胸包。商品图片、店铺、规格、价格、销量与评价均用于产品体验，不代表真实在售商品资料或商家承诺；正面、侧面与背面图片为生成的款式示意。

正式业务应用需接入企业商品数据库及授权数据服务，关联真实商品编号、规格、图片、价格、库存、评价与详情链接，并保持信息更新。缺少相关资料的项目保留为未知。

当前内置商品的外部入口为同名搜索，搜索结果需进一步核对品牌、款式与规格。页面展示部分评价，完整评价需在对应商品页面查看。当前体验范围不包含订单、支付、实时全网比价与实时库存查询。

5. 访问与使用说明

网页采用 Render 免费实例部署。闲置后服务可能休眠，再次访问时可能需要约 50 秒或更久完成唤醒。聊天响应还受到网络、服务负载及模型生成时间影响。遇到暂时无响应，可稍后刷新或重试。

模型服务使用 DeepSeek。需要模型理解或生成内容的对话会产生 Token 用量，用量与输入、上下文和回答长度有关，费用按服务商实际计费规则结算，由服务运营方的 API 账户承担。

浏览商品、查看已有详情与评价、操作购物车及读取本地历史本身不产生模型 Token 用量；部分属性问答可直接读取商品资料。会话记录保存在当前浏览器，暂不支持跨设备同步。需要模型处理时，相关输入与必要上下文会发送至模型服务，建议避免输入敏感个人信息。

6. 后续规划

后续将优先完善真实商品、库存与评价数据接入，持续优化复杂表达、风格偏好与多轮需求理解。语音输入、图片上传识别、账户同步及用量管理列为后续拓展方向，当前版本尚未提供。

体验版商品资料用于功能体验。实际选购请以核实后的商家商品信息为准。
