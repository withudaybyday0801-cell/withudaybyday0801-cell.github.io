## 重跑

```sh
python -m unittest discover -s tests -v
```

安装Playwright和Chromium的开发机器可用：

```sh
python tests/preview_server.py
node tests/browser_acceptance.cjs
```

基础UI错误恢复检查可用：

```sh
BAG_TEST_URL=http://127.0.0.1:8145 node tests/browser_flow.cjs
```

`preview_server.py` 是明确标注的离线测试夹具，不可作为Render启动命令。线上始终使用 `python start.py`。
