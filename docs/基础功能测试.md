# 基础功能测试记录

本轮版本：统一模拟商品库、渐变聊天框与一次性操作按钮。

## 已通过

自动化数据及HTTP接口：14项，通过。

- 22款商品ID、SKU、系列标识和图片索引各自唯一。
- 每款重量、容量、规格、销量、好评率、评价与店铺数据完整；回答上下文与页面记录一致。
- 清理已填规格仍写“未显示”的局限文案。
- 蓝色、浅蓝、藏蓝语义；排除色；清新少女、机能和简约筛选。
- 预算、电脑尺寸、宽肩带、防雨条件筛选。
- 单品及比较按准确商品ID组装数据，不附追问。
- 推荐按钮先澄清用途，不立即堆商品，不调用模型。
- 初始化、图片与商品详情独立地址。
- 缺少密钥、空输入、比较数量错误、跨站请求处理。
- 模型空正文有界重试、文本块返回解析及JSON格式修复。

浏览器实际交互：通过。

- 首页商品卡、标题与图片打开对应详情，详情包含规格及评价。
- 每张商品图使用独立索引，模拟说明仅在底部展示。
- 商品外部入口为HTTPS同名搜索；不把它标成准确SKU购买链接。
- 购物车重复记录去重，单件及多件商品带入输入框，发送时目标ID正确。
- 单品分析、对比表、详情链接及选品入口。
- “选品推荐”发送“请帮我推荐一款背包”并出现用途追问。
- 已回答的追问收起，功能按钮不持续高亮。
- 黑色正文、重点短语粗体、相关问题可点击。
- 失败提示及重试，重试保留目标且不重复插入用户消息。
- 刷新保存购物车及聊天；历史记录、新对话及 /clear。
- 商品详情独立链接 `/?product=ID` 可直接访问。
- 手机390×844与桌面1440×1000，没有横向溢出，没有JavaScript报错。

## 测试范围

使用本地服务及受控模型响应，未使用真实DeepSeek密钥，不代表已验证外部模型的可用性、账单余额或线上Render部署状态。模型写作自然程度及长对话表现仍应在部署后用真实请求抽查。

当前规格、评论、销量、好评率、店铺及服务等为作品模拟数据，不代表真实品牌商品表现。所有组件读取同一份模拟商品记录，真实导入记录不自动补造这些指标。

## 重跑方法

数据及接口：

```sh
python -m unittest discover -s tests -v
```

浏览器（需本机已安装Playwright及Chromium）：

```sh
PORT=8143 python start.py
BAG_TEST_URL=http://127.0.0.1:8143 node tests/browser_flow.cjs
```

浏览器脚本本身拦截模型接口，不会消耗DeepSeek Token。
