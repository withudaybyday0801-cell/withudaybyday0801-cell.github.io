# v12：按问题回答与商品多视图

本次保留现有选品条件、购物车、比较、配色和单次模拟数据说明。

- 明确的“分析商品”操作和所选 SKU 优先于商品名中的颜色、风格词，不再触发重新推荐。
- 常见问题按 29 类主题读取商品事实，直接回答防水、肩带、透气、电脑适配、收纳等问题。复合问题可同时回答多个主题，不修改选品条件。已知事实问题不额外调用文案模型。
- 补齐 64 款模拟商品的后台属性：背板网布、通风槽、肩垫厚度、建议负重、电脑内仓尺寸、书本适配、伞杯尺寸、洗护、耐脏与耐用说明、袋位数量、版型、拉链、充电接口和反光等。护脊不按医疗效果宣传，防泼水不等同整包防水。
- 每款提供透明背景正面、侧面、背面三张模拟图片，可在详情切换；这些是生成的款式视图，不是商家实拍。真实上线须替换成经授权的同 SKU 图片并核对实物结构。
- 商品详情仅展示 8 项关键属性。关闭按钮随弹窗滚动保持可见，新开弹窗回到顶部。桌面聊天输入框收窄至 680px，移动端适配屏宽，渐变配色保持。
- “这款”指代不清、当前有多款时，先让用户选定；不擅自分析第一款。真实导入商品缺失的属性保持未知，不自动填入模拟参数。

## 原因与边界

此前的问题主要是分析/推荐意图互相覆盖、属性资料不足，以及问答逻辑复用了推荐介绍。模型参数量不是界面里可以补几项就增加的设置；本次补的是商品数据字段、路由规则与问题回答规则，并非训练或微调 DeepSeek 模型。复杂的新表达仍需线上真实模型回归与持续扩充评测集。

## 验证

`python -m unittest discover -s tests -q` 包括 41 条消费者问法 × 64 款商品、64 款明确分析操作、现有筛选与数据边界等检查。

浏览器测试覆盖原有 25 组对话、选品场景切换、历史补充商品条件、购物车与比较等既有检查，以及 64 款三视图切换、8 项关键参数、底部关闭弹窗、分析→防水→肩带的连续问答、桌面/手机宽度。

本地回归使用真实规则引擎和目录，模型调用由离线测试夹具替代。当前环境没有生产模型密钥，未对线上 DeepSeek 的开放式理解效果作验证。
