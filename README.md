# 包懂你

中文背包选购作品。当前商品库为64款独立的模拟商品，界面底部统一说明数据性质。每款拥有独立SKU、系列及图片画框；商品文案、卡片、详情和比较表读取同一份数据。

## 部署

本次已改为完整项目，不能只下载或替换 `bag_local.py`。请保留整个仓库，尤其是 `bag_engine.py`、`data/catalog.json` 和 `bag-assets/catalog-sheet-*.png`。

Render Web Service：

- Build Command：`python -m py_compile bag_local.py bag_engine.py start.py`
- Start Command：`python start.py`
- Environment：`BAG_AI_KEY` 填自己的DeepSeek密钥；可选 `BAG_AI_BASE_URL=https://api.deepseek.com`、`BAG_AI_MODEL=deepseek-chat`。
- 更新后选择 Manual Deploy → Deploy latest commit。无需改动已有密钥。

本地使用：下载并解压整个仓库，在项目文件夹运行 `python bag_local.py`，按提示在终端输入密钥，不写入文件。

## 本轮重做内容

1. 64款商品覆盖不同颜色、风格、电脑尺寸、宽肩带、分区、托特/斜挎/胸包及户外防雨需求。默认选背包，明确要求其他品类时再切换。
2. 把本轮需求表示为新增、替换、移除操作；不从历史恢复已经取消的条件。轻便只影响排序，明确的重量数字才是硬上限。
3. 匹配后一般展示5款主推及5款备选，有更多符合商品时可继续查看；不为凑数放宽条件。
4. 推荐文字只介绍符合要求的商品本身。指定商品问重量、评价或不足时，直接读取该商品资料。
5. 模型可改写自然表达，不能修改商品集合；商品ID、关键数值和结构属性不一致的生成结果不会显示，改用可核对的商品资料描述。
6. 输入框、购物车、对比、历史保存、相关问题等原有交互保留。旧版本聊天可以阅读，但不继续使用旧商品ID绑定，建议更新后新建对话。

这不是训练或微调DeepSeek模型，也没有新增模型权重。实现方式是模型语义解析、明确条件校验、商品检索及事实约束。

## 验收

- [25条离线验收记录](docs/25条需求验收记录.md)：条件、数量、删除要求与文字/商品绑定。
- [基础功能测试](docs/基础功能测试.md)：测试范围和未验证部分。
- `python -m unittest discover -s tests -v`：目录、25条明确语义、HTTP及错误边界测试，无外部模型调用。

真实模型验收需要运行中的当前版本网页和网页服务端配置的密钥。本次开发环境没有密钥、也无法访问线上网页，因此未执行真实DeepSeek验收，不把离线通过表述为“模型已训练好”。部署后可执行：

```sh
python tools/acceptance_live.py https://baodongni.onrender.com
```

该脚本会发送原来的25条问题及连续修改，保存逐条结果，会消耗所部署服务对应账户的Token；不要用于别人的网页。无需把密钥发给脚本或聊天。

## 数据与费用

真实商品导入参见 [真实商品数据接入](docs/真实商品数据接入.md)。模拟指标不代表真实品牌性能、店铺承诺或实时销量。外部链接仍为明确的同名搜索，内置详情地址为 `/?product=ID`，不伪造购买SKU链接。

打开网页、看商品、加入购物车不会调用模型。复杂语义提取与文案改写会调用；入口追问和已知商品的重量、容量、评价、缺点可以直接按资料回答。重试也可能产生额外Token费用。

本轮展示修复：主图使用独立裁切画框；卡片使用完整标题；每轮“查看更多”保留当时条件并共用服务端筛选。旧消息没有条件快照时，请重新发送一次需求，不推测旧条件。
